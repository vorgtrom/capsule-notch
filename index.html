Capsule

A small glass capsule on the edge of a Windows screen.

Capsule is a personal Windows app. It shows Claude Code and Codex usage limits, whether a Claude Code session is working or waiting, ideas sent to Notion, and, once connected, when your next Google Calendar event starts.

It runs entirely on your own PC. There is no Capsule server, account or website beyond this page.
