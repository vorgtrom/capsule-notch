Privacy policy

Effective 24 October 2026.

Capsule is a Windows app that runs only on your own PC. It has no server: nothing it reads is sent to its developer or to anyone else.

Google Calendar and Google Tasks

When you connect Google Calendar, Capsule asks Google for access to your events, read-only access to your list of calendars, and access to your Google Tasks. It uses them only to show, on your own screen, when your next event starts, what is on today and tomorrow, and a month of your events and tasks.

Capsule changes your Google data only when you ask it to, on its month page: it adds the event or task you typed, marks the task you clicked as done or not done, or changes or deletes the event or task you chose. It never changes events you were invited to.

  • Event and task titles, and calendar and task list names, are shown on screen only. They are kept in memory while Capsule runs, and are never written to disk, logged or sent anywhere.
  • To stay signed in, Capsule keeps the sign-in Google gives it (a refresh token) on your PC, encrypted for your Windows account. Short-lived access tokens are kept in memory only.
  • Capsule talks only to Google's own servers (oauth2.googleapis.com, www.googleapis.com, tasks.googleapis.com and calendar.google.com) for this.
  • Capsule doesn't sell, share or transfer your Google data, use it for advertising, or let anyone read it.

Capsule's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other features

Your choice of which panel section opens first is stored in Capsule's local settings.

Capsule also reads your Claude Code and Codex usage from Anthropic and OpenAI, and sends ideas you type to your own Notion database, each with your own sign-in for that service. That data, too, goes only between your PC and that service.

A downloaded Capsule asks GitHub once a day for the newest release's version number, so it can tell you when an update is out. That request carries no sign-in and nothing about you, and you can turn it off in Capsule's menu.

Needs you and GitHub checks

The Needs you tile reads pending request status from Capsule's local request queue. It stores no prompt text or approval history.

GitHub checks start off. If you save a public repository, Capsule requests public pull request and Actions metadata from api.github.com without signing in. Capsule saves the repository name in its local settings. It keeps responses and cache validators in memory. Turn off GitHub checks in Settings to stop these requests and clear the cache.

Screenshots, scrolling capture, and clipboard images

Capture reads the screen rectangle you select on one physical monitor. Scrolling capture visibly scrolls the selected page in Edge or Chrome. Capsule keeps capture pixels and crop images in memory while the preview is open. It does not upload them, log page content or addresses, or add private paths to its settings.

Capsule changes the clipboard only when you choose Copy. Save PNG writes to your chosen destination. Keep on shelf writes the current image to the Windows temporary folder. Closing the preview releases its capture and crop buffers. Copies and saved files can remain outside Capsule. Windows and other clipboard tools can handle copied images according to their own settings.

Capture does not enable clipboard history. If you already enabled history, its normal clipboard watcher can retain an explicit copy in memory. Each retained image is limited to 16 million pixels and 8 MiB of PNG data. Capsule keeps at most five images and 32 MiB of PNG data across them, removing the oldest images first. Turning history off clears the list. Capsule does not save or log this history.

Shelf

The shelf keeps up to 12 file paths in memory for the current session. Capsule leaves the original files in place and offers paths to the local app where you drop them. Capsule does not log or upload shelf paths or files.

Capsule stages up to 12 captures and 64 MiB of generated PNGs in the Windows temporary folder per session. Removing a row leaves its PNG available until exit and does not free its capture space. Capsule deletes only its staged files on normal exit. A crash or a file still open in another app can leave a PNG in that folder.

Removing access

Choose Sign out in Capsule's settings: it deletes the saved sign-in and asks Google to revoke it. You can also remove Capsule at any time from your Google Account, under Security → Your connections to third-party apps & services. Delete %USERPROFILE%\.capsule to remove Capsule's saved settings and logs.
